# 晨星共行 (Morning Star Companions)

> 「直等到天發亮，晨星在你們心裏出現，你們就作得好了。」（彼後一19）  
> 「你要逃避青年人的私慾，同那清心呼求主的人，竭力追求公義、信、愛、和平。」（提後二22）

專為召會生活與聖徒讀經追求設計的**主題式共讀與彼此激勵平台**。幫助聖徒與活力同伴規律追求《聖經恢復本》、生命讀經與職事書報，每日打卡、發表摸著與亮光、留言互勉與彼此阿們。

---

## ✨ 核心功能

- **📖 追求主題與自動排程**：
  - 支援生命讀經、聖經加註解、屬靈經典、每週晨興聖言。
  - **半年新約一遍**：內建 130 天自動排程，每天兩章從馬太追求至啟示錄。
  - **新約速讀**：自選期程（30/60/90/120天），自動比對進度、超前/落後提醒與累計遍數統計。
  - 支援「一次設定進度」與 10 秒即時防呆復原機制。
- **🗺️ 追求地圖 (Pursuit Map)**：
  - 位於右側側邊欄的精緻小巧方格熱力圖，清楚顯示當月每一天的追求篇章數（如 `+2章`）與強度色階。
- **💬 亮光分享與動態牆**：
  - 發表今日摸著亮光，自動同步打卡；動態牆嚴格跟隨當前主題，支援多行留言與阿們互動。
  - 全站刪除操作配備 7 秒 Toast 立即復原。
- **🏕️ 晨興帳幕與信物藏寶庫**：
  - 依追求進度自動解鎖格子容量與屬靈信物，支援自訂經文橫額與走訪同伴帳幕互勉。
- **🛡️ 管理員控制台與批量處理**：
  - 手風琴條列檢視、6-Emoji 邀請碼管理、聖徒名冊與進度重設。
  - 支援全選批量指派、移出與權限設定，具備管理員身分絕對安全保護機制。
- **🌙 深色模式與外觀氛圍**：
  - 支援「☀️ 晨光淺色 / 📜 溫潤書卷 / 🌙 夜更深色」三種模式，柔和沉穩不刺眼。

## 🚀 快速開始

### 1. 安裝與啟動

```bash
# 安裝相依套件
npm install

# 啟動開發伺服器
npm run dev
```

開啟瀏覽器造訪：**http://localhost:3000**

### 2. 環境變數（選填）

若需使用真實信箱收取驗證碼，可於 `.env.local` 設定 Gmail SMTP（未設定時自動啟用畫面模擬驗證碼，不影響功能）：

```env
SMTP_HOST="smtp.gmail.com"
SMTP_PORT="465"
SMTP_SECURE="true"
SMTP_USER="your-email@gmail.com"
SMTP_PASS="your-16-char-app-password"
SMTP_FROM="晨星共行 <your-email@gmail.com>"
```
